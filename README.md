# 世界教室・國際體驗營｜網站 V1

這是 GitHub Pages 可直接部署的靜態前台原型。

## 目前功能
- 手機優先響應式版面
- UEIS 主色系概念：酒紅＋全亮白＋低飽和米灰
- 營隊特色、三天行程、住宿、費用、早鳥資訊
- 一站式報名表 UI
- 個資告知與肖像授權分開
- 報名表目前為「安全示範模式」：不會送出或儲存任何資料
